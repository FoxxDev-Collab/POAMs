# POAMs Web Application - Implementation Plan

## Overview
A .NET 8 LTS web application for managing Plan of Action and Milestones (POAMs) for a small cybersecurity team. Replaces existing PowerShell/MS Access solution.

## Technology Stack
- **Framework**: ASP.NET Core 8 MVC + Razor Pages
- **Database**: SQLite with Entity Framework Core
- **Authentication**: Windows Auth (AD) + Local Identity fallback
- **Deployment**: IIS Web Deploy
- **CSS Framework**: Bootstrap 5 (clean, professional UI)

## Role Structure
| Role | Access Level |
|------|--------------|
| Admin | Super user - full system access, user management, all CRUD |
| ISSM | Manager - create/edit POAMs, assign users, view all data |
| ISSO | User - work on assigned POAMs/milestones, update status |
| SysAdmin | User - same as ISSO |
| Auditor | Read-only - view all POAMs, milestones, reports, exports |

## Security by Design Features
1. **Authentication**: Hybrid Windows Auth + Local Identity
2. **Authorization**: Role-based with policy enforcement
3. **Audit Logging**: All CRUD operations logged
4. **Input Validation**: Server-side validation, anti-forgery tokens
5. **SQL Injection Prevention**: EF Core parameterized queries
6. **XSS Prevention**: Razor auto-encoding, Security headers
7. **HTTPS Enforcement**: Required in production
8. **Password Policy**: Strong passwords for local accounts (12+ chars, complexity)
9. **Session Security**: Secure cookies
